## 🚧 What I'm Building

### 🐷 [Mr Gholak](https://mrgholak.ir)
**Personal Finance Management**

A Persian-first financial management application focused on making personal finance easier and more accessible.

- Income and expense tracking
- Budgeting and financial insights
- Installments, debts, and savings
- PWA and Android experiences
- Notifications and smart financial tools

Tech: React Native · Expo · JavaScript · Supabase · Cloudflare

### 🎨 [Moodify](https://moodifyweb.ir)
**A Mood-Based Web Experience**

An experimental web project exploring interactive experiences, frontend development, and thoughtful interface design.

Tech: React · Vite · JavaScript · Cloudflare Workers

### 📝 DevTrail
**An Offline-First Markdown Workspace**

A personal project exploring cross-platform desktop development and local-first software.

- Markdown-native notes
- Minimal editing experience
- Offline-first architecture
- Desktop and Android ambitions

Tech: React · TypeScript · Tauri · CSS

**E-commerce Experiments**

Exploring modern web interfaces, shopping experiences, and frontend product development.
